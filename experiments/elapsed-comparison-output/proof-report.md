# Scoped elapsed comparison output proof

Issue: https://github.com/callin2/ghostflow-language/issues/590#issuecomment-6483936760

The certificate binds the canonical literate source to the current production compiler's complete GFB3 module, its two Bool outputs, and selected observation metadata. The existing first output remains `relay <- held'`. The second output becomes `expired <- age >= 3000ms`.

`ComparisonSource` independently reads the original UTF-8 source envelope and its bounded control grammar. It reuses the existing sensor, Bool state, recovery, next-state, and elapsed declaration readers. Its suffix reader admits one Bool output connected to the declared timer with exactly `>= 3000ms`, checks distinct names, and checks declaration node 19 and connection node 23.

`ComparisonModule` admits the complete module through existing epoch header, input, initial state, and transition readers. It checks the complete strategy capability bytes, both output names and physical Bool types, output count, constraint count, and absence of trailing bytes. Separate certificates bind every expression body and the projected sensor, recovery, timer, output, connection, and requested-dependency metadata.

`ComparisonMachine` adds exact constant-table entries for the little endian binary64 encodings of 3000 and mutant 3001, and Nat comparisons for opcode 17 (`>=`) and mutant opcode 16 (`>`). Every other output instruction delegates to the unchanged `DurationMachine.step`. The executor requires exact terminal PC and one terminal value within `code.length + 1` fuel. The observer rejects a numeric result. It preserves the existing epoch, relay request, and fault/recovery events in each observation.

The theorem `original_comparison_trace` quantifies over every `AcceptedFrom 0` history. It uses unchanged `EpochMachine.rawTrace`, `all_histories`, and `ElapsedClockBounds.source_history_bounds`. It proves that the admitted module's observations equal independently read source observations, with existing epoch clock bounds. The source observation evaluates the threshold against `expressionAge before input`. A resetting scan can therefore have `expired = true` while its newly committed timer age is zero.

The mutation checks first prove that altered expression bytes are structurally admitted and execute with a concrete wrong Bool observation. They then reject the exact theorem asserting equivalence with the canonical source. This order distinguishes a valid model counterexample from an infrastructure or loader failure. Metadata and malformed source failures target the exact failed admission theorem. The runner rejects unexpected diagnostic lines, missing tools, signals, timeouts, resource limits, and unchecked proof declarations. Each run writes `running` before its first external probe so an old successful receipt cannot survive a failed new run.

The model's constant table is an explicit representation assumption. Reading 3000 from actual production bytes in Node and binding those bytes in Lean does not prove general IEEE-754 decoding, f64 subtraction or comparison, Rust VM correspondence, clock-admission refinement, general compiler correctness, safe-output resolution, or physical behavior. Runtime replays are separate integration evidence. No timer reset machine, epoch state machine, old proof model, compiler, or runtime implementation changes are included.
