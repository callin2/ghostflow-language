# REF-04-065 증명 범위 밖의 제약 실행

선택적 중복 제약 검사기는 출력 이름을 최대 여덟 개까지 처리합니다.
REF-04-065 회귀 시험은 아홉 개 출력을 포함하는 동일한 mutex 두 개를
정본 컴파일러로 컴파일합니다. 산출물에는 제약 두 개가 남고 증명
인증서는 없습니다. 같은 바이트코드를 네이티브 Rust 실행기와 framed
WASM에서 실행합니다. 두 실행기는 충돌하는 요청을 차단하고 이후 스캔에서
한 출력만 요청하면 그 출력을 허용합니다. 두 기록 모두 제약 관측이 두 개입니다.

이 시험은 컴파일러가 지원 범위에서 증명을 성립시키지 못했을 때의
실행을 다룹니다. 검사기의 시간 초과 예외와 미확정 반환은 기존 검사기
시험에서 확인합니다. 기존 REF-04-065 시험은 잘못된 물리량, 암묵적
Result 연산, 시간창 한도와 스칼라/PID 롤백을 다룹니다. 원래 사례는
specified 상태를 유지합니다. 한 tick에서 제어기 갱신 후 자원 갱신이
실패하는 경우를 검증하려면 보호된 Percent 연결과 안전 출력 권한을
정의한 실행 프로필이 필요합니다.
