# Reference feature maturity and evidence

Each row describes the named Reference clause, not its whole chapter. `CORE` owns compiler/runtime primitives beyond the frozen Core 0.1; `coreScope` marks frozen membership. `LIBRARY` means outside that frozen contract and does not assert that a user-authored pure library exists. External-owner maturity reflects evidence in this toolchain, not a release judgment on another module.

A verified link identifies an exact active test selector and its assertion class in the catalog. It establishes an executable oracle link; the current full verification gate determines whether it passes. Compile, native/WASM, host simulation, Driver application, and physical confirmation are separate stages.
