# 언어 설계 메모

선택된 표면 문법은 이름이 있는 `control`, 형식이 지정된 선언, 명시적인 다음 상태 방정식, 출력 의도 연결로 구성됩니다. 리터레이트 소스는 같은 실행 의미와 매핑된 진단을 유지하면서 가까운 곳에 설명을 추가합니다. 컴파일러와 이식 가능한 런타임은 함께 버전 관리되므로 하나의 프로그램을 네이티브/WASM 추적으로 살펴보고 호환되는 Device 호스트에서 사용할 수 있습니다.

상태 경계, 제한된 표현식 비용, 제약된 효과, 명시적인 호스트 입력은 실행을 재현 가능하게 합니다. 선택적 센서나 설치 메타데이터가 물리 장비에 관한 가정을 조용히 만들어서는 안 됩니다. 공유 스테이션 제약은 명시적인 바인딩을 가진 실행 가능한 소스 또는 프로파일 계약입니다.

상세한 [언어 계약](LANGUAGE.md), [제어 표면](LANGUAGE-SURFACE.md), [리터레이트 규칙](LITERATE.md), [제약 조건](CONSTRAINTS.md)은 선택된 문법과 설계 제안을 구분합니다. [구현 경계](IMPLEMENTATION.md)는 유지되는 실행 가능 부분집합을 설명합니다.

비공개 대화와 마이그레이션 작업 기록은 이 독립 소스 내보내기 바깥에 보관됩니다. 이 페이지에는 언어 수준의 근거만 담습니다.
