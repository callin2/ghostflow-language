# 언어 설계 메모

이 페이지는 GhostFlow 설계의 바탕에 있는 언어 수준의 근거를 요약합니다.

**선택한 표면 문법.** GhostFlow 프로그램은 이름이 있는 `control`입니다. 그 안에는
다음이 들어 있습니다.

- 타입이 지정된 선언
- 명시적인 다음 상태 방정식
- 출력 의도 연결

문서형 소스(literate source)는 코드 바로 옆에 설명을 둡니다. 실행 의미와 매핑된
진단은 그대로 유지됩니다. 컴파일러와 이식 가능한 런타임은 함께 버전 관리됩니다. 그
결과 하나의 프로그램을 native 추적과 WASM 추적으로 살펴본 뒤, 호환되는 Device
호스트에서 그대로 사용할 수 있습니다.

**재현 가능한 실행.** 다음 네 가지 속성이 실행을 재현 가능하게 만듭니다.

- 명시적인 상태 경계
- 제한된 식 비용
- 제약된 효과
- 명시적인 호스트 입력

선택적 센서나 설치 메타데이터가 물리 장비에 대한 가정을 조용히 만들어 내서는 안
됩니다. 공유 스테이션 제약은 명시적인 바인딩을 가진, 실행 가능한 소스 계약 또는
프로필 계약입니다.

**더 읽을거리.** 상세한 [언어 계약](LANGUAGE.md), [제어 표면](LANGUAGE-SURFACE.md),
[문서형 소스 규칙](LITERATE.md), [제약](CONSTRAINTS.md) 문서는 선택된 문법과 설계
제안을 구분합니다. [구현 경계](IMPLEMENTATION.ko.md)는 유지되는 실행 가능 부분집합을
설명합니다.

비공개 대화와 마이그레이션 작업 기록은 이 독립 소스 내보내기 바깥에 보관됩니다. 이
페이지에는 언어 수준의 근거만 담습니다.
