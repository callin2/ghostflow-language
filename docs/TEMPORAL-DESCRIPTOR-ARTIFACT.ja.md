# 実行が保留された時間的アーティファクト

このページでは、時間的（時刻や自然現象に依存する）宣言に対してコンパイラが何を生成するか、そしてその出力が実行可能**ではない**のはどのような場合かを説明します。

**実行可能な自然条件。** `tide_is`や`moon_is`などの自然条件に対しては、正本の`.ghost.md`コンパイラが実行可能なGFB11を出力します。付随する`GhostFlow/control-v10`マニフェストには、それらの型付きプロバイダディスクリプタが保持されます。ただし、コンパイルしただけでは実行できません。

- ランタイムでの有効化には、宣言されたプロバイダバインディングを含む明示的なコンテキストプロファイルが必要です。
- プロバイダの観測は、分類、カバレッジ、有効期限、不確実性、位置／タイムゾーン、リビジョンの証拠を伴っていなければなりません。
- 呼び出し側は、保護されたResult射影を直接与えることはできません。

**保留される`after_event`宣言。** 使用されておらず明示的な射影も持たない`after_event`宣言は、その実行契約が利用できない場合、検査済みの`GhostFlow/temporal-descriptor-artifact-v1`のまま残ります。このJSONアーティファクトは**GFBバイトコードではありません**。ペイロードと付随するマニフェストの両方が`executable: false`を宣言します。

**アーティファクトが保持するもの。** アーティファクトは、抽出された`control`ソースの全体と型付きディスクリプタを保持します。通常のソース文書エンベロープは、文芸的（literate）テキストそのもの、そのSHA-256、およびソース位置を保持します。検証ではその正本ソースを再コンパイルします。バイト列の改変、ディスクリプタマニフェストの改変、ソース同一性の改変はいずれも拒否されます。

保留されたディスクリプタについては、`requiredRuntimeContracts`が不足している実行境界を示します。

- `identified-event-delivery`と`per-identity-result-projection`：実行可能な射影を持たない、使用されていない`after_event`宣言であることを示します。

`ControlRuntime`は、保留されたディスクリプタマニフェストを拒否します。また、必要なコンテキストの有効化やプロバイダバインディングを欠いた、実行可能な自然条件アーティファクトも拒否します。コンパイルが成功しただけでは、ランタイムへの適合やデバイスへの配備は証明されません。

**実行可能な`after_event`射影。** [after_event WASM ABI](AFTER-EVENT-WASM-ABI.ja.md)は、識別付きの配信、ネイティブなアイデンティティごとの結果、そして明示的な`after_event_any`および`after_event_all`射影を、1つの`control`トランザクションの中で実行します。いずれかの射影を使用するソースは、実行可能なGFBにコンパイルされます。コンパイラが、単独の、あるいは使用されていない信号に対して射影を推論することは決してありません。
