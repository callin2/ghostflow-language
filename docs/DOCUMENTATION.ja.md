# ドキュメントカタログ

[한국어](DOCUMENTATION.ko.md) · [言語ポリシー](DOCUMENTATION-LANGUAGES.ja.md)

このカタログは、英語と韓国語の両方で提供されているGhostFlowのドキュメントを一覧にしたものです。各行は、同じドキュメントの完全な英語版と韓国語版にリンクしています。

表の読み方：

- **ドキュメント**は正本ソースのパスです。既存の正本パスはそのまま維持されます。翻訳によって原文が移動することはありません。
- **英語**と**韓国語**は、2つの言語版へのリンクです。原文の`NAME.md`が英語の場合、韓国語版は`NAME.ko.md`です。原文の`NAME.md`が韓国語の場合、英語版は`NAME.en.md`です。これらの規則は[言語ポリシー](DOCUMENTATION-LANGUAGES.ja.md)で説明しています。
- 翻訳されたプログラム例は、あくまで*読むための投影*です。プログラムをコンパイルするときは、必ず原文の`.ghost.md`ドキュメントを使用してください。
- レポート、生成された証拠（エビデンス）、テスト入力は、それぞれ理由を添えた明示的な除外項目として[マニフェスト](translations.json)に記載されています。
